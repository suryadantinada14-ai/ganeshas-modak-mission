## Supabase integration checks

The integration is optional and configuration-driven. `src/supabase.js` uses the Supabase REST API with only the publishable/anon key. The SQL schema creates `game_scores`, a read-only `leaderboard` view, RLS read access, and a security-definer `submit_game_score` function with range checks. Direct anonymous inserts are not permitted. Without `supabase-config.js` credentials, the game never calls the network and uses local records.

A live Supabase project was not connected in this environment, so the network path still requires a user-owned project configured with `supabase-schema.sql`. Verify one score submission, leaderboard retrieval, invalid-score rejection, and the offline fallback after configuration.
