# Contest submission

**Game:** Ganesha’s Modak Mission — Contest Polish v3  
**Tagline:** Sneak. Solve. Celebrate.  
**Genre:** Family-friendly stealth / puzzle adventure  
**Game link:** https://ganeshas-modak-mission.raghu4359.chatgpt.site/

On Ganesh Chaturthi morning, Ganesha notices Maa Parvati’s fresh modaks. Playful mischief becomes a shared preparation mission: sneak through a decorated home, collect festival offerings, recreate a rangoli, and send Mushak through a tiny passage. Maa Parvati investigates sounds and searches for Ganesha with affection. Complete the checklist to illuminate the pandal and celebrate together.

**How to play:** Collect any five modaks, 3 flowers, 3 durva, 2 diyas, 3 decorations and complete the rangoli. Touch a collectible to pick it up. Use the Festival Box to reveal a golden modak; Mushak’s tiny lever reveals the optional secret modak. If Ganesha is caught by Maa Parvati, the run ends immediately with GAME OVER; nobody is harmed.

**Controls:** WASD/arrows move; Shift run; E interact; Space hide; Q switch; Tab objectives; Esc pause. Mobile provides a direction pad and labeled action buttons, objectives and pause.

**Features:** One connected level; five-state Parvati AI with obstacle-aware vision and navigation; noise distractions; three short puzzles; playable Mushak; progressive help; animated celebration; score breakdown; three replay challenges; local personal bests.

**Tools used:** JavaScript, Canvas 2D, Web Audio, HTML/CSS, Node.js built-in test runner, Git, ChatGPT/Codex coding assistance, Chromium browser QA and Sites hosting. No runtime/build libraries or external services are required by the game itself.

**Assets:** Procedural drawings and synthesized sound; system fonts/emoji. No imported commercial game assets or copyrighted commercial recordings.

**Compatibility/testing:** Chromium desktop and 320/390-pixel browser layouts checked. 36 automated tests pass, including a simulated movement-based complete route. Production build succeeds. Physical iPhone/Android, Safari and Firefox remain untested. See TESTING.md for limitations.
